# SHIBUYA STREET SALES DASHBOARD


A sales dashboard built for my anime merch store --- SHIBUYA STREET. My aim was to see which products generated more revenue, when saled were at its peak.So as to make smarter decisions


TOOLS USED: Excel--- pivot tables, formulas, data visualization

ABOUT THE DATA: Since Shibuya Street is a newly launched brand,the data used are simulated and modeled to reflect realistic patterns and orders.This was done so I could practice building a full dashboard before applying it to real data and numbers

WHAT I FOUND : Posters generated the most revenue outselling phone cases and accessories combined-- future ad spend and restock should prioritize this category

Revenue grew steadily from June into July before leveling off in August, suggesting the initial launch buzz needs a follow up campaign to sustain momentum
